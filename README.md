# Food Invoice Generator

A single-page invoice generator for food orders, written in plain HTML and JavaScript.

**Live:** https://invoice-generator-nine-lime.vercel.app

## Features

- Create and print food invoices in the browser
- No build step: one HTML file

## Tech stack

- **Frontend:** HTML, CSS, JavaScript
- **Hosting:** Vercel

## Getting started

```bash
open invoice-generator.html
```
